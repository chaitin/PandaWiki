# 知识库需求文档

## 项目简要介绍

带 AI 问答功能的 Wiki 知识库系统。  

## 用的技术

后端：Java 17 + Spring Boot 3，数据库用的 PostgreSQL，数据库迁移用 Flyway，缓存用 Redis，中间件用 Docker 跑。

后台管理页面：React + Vite + MUI 组件库 + ECharts 图表。

用户前台页面：Next.js + MUI。

## 系统有哪些功能

### 知识库管理

可以创建知识库。支持多个知识库同时用。知识库里的文档写完之后要发布，发布后用户才能在前台看到。

### 文档管理

增删改查，支持建文件夹嵌套。编辑器是富文本的，可以 Markdown 编辑。文档可以拖拽排序、挪到别的文件夹。可以设置文档的可见性权限。

### AI 模型管理

可以配置大模型，支持对话模型、向量模型、重排序模型、文档分析模型、图像分析模型这五种。对接的是 OpenAI 兼容协议，所以 DeepSeek、通义千问这些都能用。

### AI 智能问答（RAG）

这个是比较核心的功能。用户在前台输入问题，系统会先去知识库里搜相关的文档，然后把搜到的内容拼进提示词，让大模型基于这些内容回答。这样回答就不会瞎编，是有据可查的。回答是流式输出的。

检索这块我用了向量检索，就是先把文档转成向量存起来，用户提问时也算出问题向量，然后算余弦相似度找最相关的文档。

另外后台编辑文档的时候，可以一键让 AI 生成一句话摘要。选中文字还可以润色、扩写、缩写、改写。编辑的时候按 Tab 还能让 AI 帮我接着写。 

### Widget 嵌入机器人

这个就是把知识库的 AI 问答功能打包成一段 JS 代码，别的网站引用一下就能出现一个悬浮球，点开就能问答。可以配置悬浮球长什么样、放哪、什么主题。

### CardAI 提示词管理

每个知识库可以自己配 AI 问答的提示词，比如让 AI 回答的时候用什么样的语气、要不要显示引用来源之类的。

### 统计看板

后台有个统计页面，能看到：
- 总访问量、用户数、IP 数
- 近 60 分钟每分钟的访问曲线
- 中国地图上用户分布（按 IP 归属地聚合到省份）
- 热门文档、来源域名、浏览器和操作系统分布
- 问答来源的占比（Web 端、Widget、机器人）
- 用户提问最多的 Top10 问题

### 人机验证

用户提问之前会弹一个数学验证码，两个随机数相加，答对了才能继续。连续答错 3 次就锁定 5 分钟。

### 文件上传

支持上传文件，存本地磁盘。也支持 URL 远程下载。做了安全措施：黑名单扩展名、路径穿越校验、禁止重定向。

### 文档导入

可以从三个地方导入文档：本地上传文件、URL 抓取网页、飞书文档 

### 用户管理

超级管理员可以创建用户、删用户、重置密码。密码用 bcrypt 加密存的。

### 反馈闭环

用户可以对 AI 的回答点赞或点踩，踩的时候可以选原因。文档底部可以评论，支持审核模式。管理员在后台能看到所有评价和评论，可以审核或删除。

### 安全设置

- 内容复制：可以设置前台文档不让复制
- 内容合规：设置屏蔽词，用户提问或者 AI 回答里包含屏蔽词会被过滤
- 水印：前台页面会叠加一层半透明的水印
