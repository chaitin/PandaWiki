API Token 本地测试页

模拟外部平台使用 API Token 调用 PandaWiki 接口（无公网环境演示专用）

基础配置

在 Admin「访问控制 → API Token」里创建后复制
可从「知识库设置 → 访问控制」页面或接口 /knowledge_base/list 获取
